This repository contains a set of scripts used to perform variational perturbation theory (VPT) calculations on the quartic anharmonic oscillator, for OSU SRP. VPT in this very simple case introduces an auxiliary parameter to the Hamiltonian, which is set by the "principle of minimal sensitivity" (PMS). This does some nice things which is explored briefly in the poster I have put up in this repo. The particular goals of this project were to explore VPT for observables other than just energy (such as density) to see where it goes, and to explore how VPT works. The scripts essentially exist as walkthroughs of the simple application of VPT for a 1D quantum system, which generate all the plots seen on the poster, while also showing a lot of the diagnostics and tinkerings that happened along the way.

I have also put up a set of LaTeX documents that I wrote for expository reasons which aren't "research", just instructional. The file titled "0D Field Theory" develops the cumulant expansion and explores diagrams in 0D, acting as a testbed for concepts that generalize to higher dimensions. The file "Quartic AO Path Integral and Diagrams" first performs a calculation on the quartic anharmonic oscillator perturbatively using a path integral formalism, at the zero-temperature limit. It isn't the most rigorous but it's rather serviceable. The way VPT naturally enters is presented, and then a diagrammatic formalism that makes connections to 0D field theory is presented, and lastly VPT is presented diagrammatically, with comments on the PMS in a diagrammatic formalism.
